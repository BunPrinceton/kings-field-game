# Free Audio Resources for King's Field Game

## Sound Effect Sources (CC0 / Creative Commons)

### Primary Sources
1. **Freesound.org** - https://freesound.org
   - Requires account (free)
   - Filter by CC0 license for no attribution required
   - Search terms: "dungeon ambient", "stone footstep", "sword swing", "torch crackle"

2. **OpenGameArt.org** - https://opengameart.org
   - Game-focused sound effects
   - Good for fantasy/dungeon sounds
   - Various CC licenses

3. **Sonniss GDC Bundles** - https://sonniss.com/gameaudiogdc
   - Annual free game audio bundles
   - Professional quality
   - Royalty-free

### Specific Sound Needs

#### Ambience (Background Loops)
- Search: "cave ambience", "dungeon atmosphere", "wind tunnel", "water drip loop"
- Recommended: Layer 2-3 subtle loops at different volumes

#### Footsteps
- Search: "stone footstep", "concrete footstep", "dungeon walk"
- Need: 3-4 variations to avoid repetition
- Surfaces: stone floor (primary)

#### Combat
- **Sword Swings**: "sword whoosh", "blade swing", "weapon swing"
- **Hits**: "sword hit", "blade impact stone", "metal impact"
- **Enemy Death**: "monster death", "creature groan", "enemy defeat"
- Need: 2-3 variations per sound type

#### Environmental
- **Torches**: "fire crackle", "torch burn", "flame loop"
- **Distant Sounds**: "distant groan", "echo howl", "far scream"
- **Special**: "door creak", "chest open", "footstep echo"

#### UI
- **Menu**: "menu click", "ui select", "button press"
- **Notifications**: "notification beep", "alert soft"

## File Format Notes
- Prefer: OGG or MP3 format for web
- Ambient loops: Should loop seamlessly
- Sample rate: 44.1kHz standard
- Bit rate: 128-192kbps sufficient for game audio

QUICK START
================================================================================

1. Import the decorator:

   import { CleaningPropsDecorator } from './src/CleaningPropsDecorator.js';

2. Add to your dungeon builder:

   const decorator = new CleaningPropsDecorator(scene, dungeonData, {
       cellSize: 4,
       propDensity: 0.25  // 25% of rooms
   });

3. Load models and decorate:

   await decorator.loadModels();
   decorator.decorateRooms();

4. Done! Dungeon now has atmospheric cleaning props.

================================================================================
CUSTOMIZATION
================================================================================

Adjust prop density:
  propDensity: 0.1   // Minimal (10% of rooms)
  propDensity: 0.25  // Default (25% of rooms)
  propDensity: 0.5   // Medium (50% of rooms)
  propDensity: 1.0   // Maximum (all eligible rooms)

Place individual props:
  propsManager.createProp(CleaningPropType.BROOM, {x, y, z}, options);

Place prop groups:
  decorator.placeGroup(PropGroups.STORAGE_PILE, x, z);

Decorate specific rooms:
  decorator.decorateRoom(room);

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Props not appearing?
  → Check: await decorator.loadModels() is called before decorateRooms()
  → Check: console for error messages
  → Check: dungeonData.rooms has valid room data

Too many/few props?
  → Adjust: propDensity in config (0-1)

Props in wrong locations?
  → Verify: cellSize matches dungeon grid
  → Verify: dungeonData has correct room bounds

Want higher quality models?
  → See: /public/assets/props/cleaning/MANUAL_DOWNLOAD.md
  → Download GLB files manually
  → Place in: /public/assets/props/cleaning/models/

Performance issues?

  → Check: Triangle count in scene
  → Consider: Batching multiple props

# Furniture Catalog - Quick Reference

## Door Collection (5 types)

### 1. Wooden Door
- **Type**: `FurnitureType.WOODEN_DOOR`
- **Features**: Cross beams, metal handle
- **Interaction**: Open/close (swing)
- **Best Use**: Standard rooms, corridors
- **Dimensions**: 1.6w × 2.4h × 0.1d units

- **Type**: `FurnitureType.IRON_DOOR`

## Condition States

All furniture can be created in 5 different conditions:

### PRISTINE
- Perfect condition
- Bright, vibrant colors
- Clean surfaces
- Lowest roughness

### GOOD
- Well-maintained
- Original colors
- Minor wear
- Standard appearance

### WORN (Default)
- Noticeable wear
- Slightly darker colors
- Surface scratches
- Higher roughness

### DAMAGED
- Heavy wear
- Much darker colors
- Visible damage
- Very high roughness

### BROKEN
- Completely worn
- Very dark, faded colors
- Severe damage
- Maximum roughness

## Quick Creation Guide

```javascript
// Import
import { FurnitureManager, FurnitureType, FurnitureCondition } from './FurnitureManager.js';

// Create manager
const furnitureManager = new FurnitureManager(scene);

// Create furniture
const throne = furnitureManager.createFurniture(
    FurnitureType.THRONE,           // Type
    { x: 10, y: 0, z: 10 },         // Position
    {
        rotation: Math.PI,           // Rotation (radians)
        condition: FurnitureCondition.PRISTINE,  // Condition
        scale: 1,                    // Scale multiplier
        interactable: false          // Can interact?
    }
);
```

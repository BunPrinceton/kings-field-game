USAGE EXAMPLES
================================================================================

Load manifest in JavaScript:
  const paintings = await fetch('/assets/paintings/manifest.json')
    .then(r => r.json());

Get random portrait:
  const portraits = paintings.paintings.filter(p => p.category === 'portrait');
  const random = portraits[Math.floor(Math.random() * portraits.length)];

Get PS1 backgrounds:
  const ps1 = paintings.paintings.filter(p => p.style === 'ps1_rpg');
